# OCV_WarpPolar（極座標変換）
## 1. 概要：画像処理の仕組み
画像を直交座標（通常の長方形）から極座標（円状）へ、あるいはその逆へ変換します。
円形に並んだ文字を真っ直ぐに伸ばして読みやすくしたり、円状の物体のキズを横一行のデータとして解析したりする際に非常に強力なツールとなります。

## 2. GUIの使い方
- **center_x / y**: 変換の中心となる座標です。
- **destination_width / height**: 出力画像のサイズを指定します。
- **max_radius**: 変換対象とする最大半径です。
- **mode**:
    - `WARP_POLAR_LINEAR`: 距離に対して線形に展開します。
    - `WARP_POLAR_LOG`: 距離に対して対数的に展開します（中心付近を詳細に展開したい場合）。
- **enable_inverse**: チェックを入れると、極座標から直交座標への逆変換を行います。

## 3. 注意点
- **8-bit**, **RGB**, **16-bit**, **32-bit** の全形式に対応しています。
- 実行時、自動的に画像全体が選択範囲として設定されます。
