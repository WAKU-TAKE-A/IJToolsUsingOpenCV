# OCV_MatchTemplate（テンプレートマッチング）
## 1. 概要：画像処理の仕組み
大きな画像（ソース）の中から、小さな部分画像（テンプレート）と最も似ている箇所を探し出す手法です。
画像全体をスキャンし、各位置での「似ていなさ（差分）」や「似ている度（相関）」を計算してスコア画像を出力します。特定のマークや部品を自動で見つけたい場合に非常に有効です。

## 2. GUIの使い方
- **src / template**: 検索対象の画像と、探したい部分画像を選択します。
- **method**: 比較アルゴリズムを選択します。
    - `TM_SQDIFF_NORMED`: 差分の二乗和。小さいほど一致（内部で1から引いて反転表示されます）。
    - `TM_CCORR_NORMED / TM_CCOEFF_NORMED`: 相関係数。1に近いほど一致。
- **threshold_of_results**: 一致とみなすスコアの閾値です。
- **enable_results_table**: チェックを入れると、一致した座標をResults Tableに一覧表示します。
- **enable_search_max_point_in_blob**: チェックを入れると、似ている領域（塊）の中から「最も似ている1点」のみを特定して抽出します。

## 3. 注意点
- 両方の画像が **8-bit Grayscale** である必要があります。
- **srcのサイズはtemplate以上** でなければなりません。
- スコア画像が新しく生成されます。明るい場所ほど一致度が高いことを示します。
