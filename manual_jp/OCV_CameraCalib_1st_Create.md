# OCV_CameraCalib_1st_Create（カメラキャリブレーション：作成）
## 1. 概要：画像処理の仕組み
カメラのレンズによる歪み（樽型や糸巻き型の歪み）を補正するためのパラメータを算出します。
チェスボードなどの既知のパターンを様々な角度から撮影した画像を用いて、レンズ固有の焦点距離や歪み係数を特定します。高精度な寸法計測や、複数のカメラを組み合わせる処理の前段として不可欠なステップです。

## 2. GUIの使い方
- **mode**: 
    - `new_calib`: 新しくキャリブレーションデータを作成します。
    - `read_calib`: 保存済みのデータを読み込みます。
- **calibration_name**: データの保存名です。
- **pattern_type**: 使用するチャートの種類（Chessboard, Circles等）を選択します。
- **pattern_cols / rows**: チャート内の「交点」の数です（例：8x6のチェスボードなら7x5）。
- **square_size_mm**: チャートの1マスの実際のサイズ（mm）を入力します。
- **input_source**: 画像スタックから読み込むか、接続されたカメラから直接取り込むかを選択します。

## 3. 注意点
- 算出したパラメータは `MyCameraCalib` 共有領域に保持され、ファイルとしても保存されます。
- 高精度な補正には、パターンの向きや距離を変えた **10〜20枚程度の画像** を用意することが推奨されます。
- キャリブレーション完了後、`OCV_CameraCalib_2nd_Undistort` で実際の補正を適用します。
