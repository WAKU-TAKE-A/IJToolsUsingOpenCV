# OCUtil_BluredImageDiff（ぼかし差分による特徴抽出）
## 1. 概要：画像処理の仕組み
1枚の画像に対して「小さなぼかし」と「大きなぼかし」の2種類を適用し、その差分を計算します。
これは画像処理工学における「DoG (Difference of Gaussians)」に近い手法で、特定の周波数成分（特定の太さの線やエッジ）だけを浮き上がらせたり、背景のムラを抑えて物体を強調したりするのに有効です。

## 2. GUIの使い方
- **small_ksize_x / y**: 1つ目の（細かい）ぼかしサイズです。
- **large_ksize_x / y**: 2つ目の（粗い）ぼかしサイズです。
- **offset**: 差分計算の結果に加算する値です。計算結果が負になるのを防ぎ、結果を見やすく調整します。通常は中間値（128など）を指定します。
- **borderType**: 画像境界の処理方法です。

## 3. 注意点
- **8-bit**, **RGB**, **16-bit**, **32-bit Float** 画像に対応しています。
- **offset** の指定範囲は画像のビット深度に依存します（8-bitなら0-255）。
