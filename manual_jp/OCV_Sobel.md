# OCV_Sobel（Sobel演算子 / 微分エッジ検出）
## 1. 概要：画像処理の仕組み
画像の輝度値の「傾き（勾配）」を計算してエッジを抽出する、最も一般的な手法の一つです。
微分の計算を行うことで、色が急激に変わる境界部分だけが明るく浮かび上がります。ノイズを少し抑えつつ、縦や横の線を強調したい場合に非常に有効です。

## 2. GUIの使い方
- **dx / dy**: x方向（縦線）かy方向（横線）のどちらを強調するか指定します。
- **ksize**: カーネルサイズ（1, 3, 5, 7）。大きくするほどノイズに強くなります。
- **scale / delta**: 結果の明るさ調整用パラメータです。

## 3. 注意点
- **8-bit**, **16-bit**, **32-bit Float** 画像に対応しています。
- **dx** または **dy** の少なくとも一方は `0` より大きくする必要があります。
