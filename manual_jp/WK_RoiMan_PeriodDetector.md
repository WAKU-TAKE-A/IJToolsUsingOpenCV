# WK_RoiMan_PeriodDetector（ROIプロファイルの周期検出）

## 1. 概要：画像処理の仕組み
選択されたROI（矩形や線など）から画像の輝度プロファイルを抽出し、自己相関関数（Autocorrelation Function）を用いて波形の反復的な「周期」を自動検出します。
干渉縞の縞幅や、規則的に並んだ物体の間隔などを自動測定したい場合に使用します。ピクセル単位の周期に加え、放物線近似によるサブピクセル精度の周期と、波形の周期性の強さを示す確信度（正規化自己相関値）も算出します。

## 2. GUIの使い方
- **detrend_method**: 信号からベースライン（トレンド）を除去する手法を選びます。基本的には波形全体の傾きを除去する `LINEAR_REGRESSION`（線形回帰）を推奨します。
- **ma_window_size**: トレンド除去手法に `MOVING_AVERAGE` を選択した場合の窓サイズ（ピクセル）です。対象とする周期よりも十分に大きな値を設定する必要があります。
- **min_period**: 検出する最小周期（ピクセル）。これより短いノイズは無視されます。
- **max_period**: 検出する最大周期。`0` に設定すると自動で計算されます。
- **peak_method**: 自己相関波形のピーク検出手法（HEIGHT または PROMINENCE）。
- **relative_threshold**: ピーク検出の相対閾値（0.0～1.0）。
- **vertical_profile**: チェックを入れると、プロファイルを水平方向ではなく垂直方向に取得します。
- **enable_refresh_data**: 実行前に Results Table の過去データを消去するかどうかを指定します。

## 3. 注意点
- 選択したROI内に十分な長さのプロファイルが存在しない場合や、周期性が全く見られない（ノイズのみ）場合はエラーとなり計算されません。
- 実行結果は Results Table に追加され、以下の値が出力されます。
  - `Period`: ピクセル精度の周期
  - `Period_Subpx`: サブピクセル精度の周期（小数点）
  - `Confidence`: 確信度スコア（1.0に近いほど強い周期性を示す）
