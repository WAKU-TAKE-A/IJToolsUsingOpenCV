# OCV_HoughLines（ハフ変換による直線検出）
## 1. 概要：画像処理の仕組み
画像内の「直線（無限直線）」を検出する古典的なアルゴリズムです。
画素の並びを(ρ, θ)というパラメータ空間に投影（投票）することで、断片的な点やノイズに惑わされず、画像全体を貫くような直線を力強く見つけ出します。

## 2. GUIの使い方
- **distance_resolution**: 距離の解像度（画素単位）です。通常は `1` を指定します。
- **angle_resolution_factor**: 角度の解像度です（π/この値）。`180` とすると1度刻みになります。
- **min_votes**: 直線とみなすために必要な最低の投票数（画素数に相当）です。
- **min / max_angle**: 検出する直線の角度範囲を制限できます（0～360度）。
- **srn / stn**: マルチスケールハフ変換を使用する場合の分割係数です。通常は `0` で構いません。
- **enable_add_roi**: 検出された直線をROIとしてROI Managerに追加します。

## 3. 注意点
- 入力画像は **8-bit Grayscale** で、かつ **事前にエッジ抽出（Canny等）を行っておく** 必要があります。
