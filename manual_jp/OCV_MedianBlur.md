# OCV_MedianBlur（メディアンフィルタ / 中間値フィルタ）
## 1. 概要：画像処理の仕組み
近傍領域の画素値を並べ替え、その「中央値（メディアン）」を新しい画素値として採用するフィルタです。
平均化ぼかしとは異なり、極端に離れた値（ノイズ）を完全に無視できるため、「ごま塩ノイズ」のような点状のノイズを除去するのに劇的な効果を発揮します。また、輪郭（エッジ）を比較的はっきりと残せるのも特徴です。

## 2. GUIの使い方
- **ksize**: フィルタのサイズです。大きくするほどノイズ除去力は上がりますが、画像がのっぺりとした絵画のような質感になります。

## 3. 注意点
- **8-bit**, **RGB (24-bit)**, **16-bit**, **32-bit Float** の各画像に対応しています。
- **ksize** は **3以上の奇数** である必要があります。
- **16-bit / 32-bit画像** の場合、**ksizeは5以下** という制限があります。
