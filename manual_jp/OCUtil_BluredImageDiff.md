# OCUtil_BluredImageDiff（ぼかし差分による特徴抽出）
## 1. 概要：画像処理の仕組み
1枚の画像に対して「小さなぼかし」と「大きなぼかし」の2種類を適用し、その結果の差分を計算します。
これは画像処理工学における「DoG (Difference of Gaussians)」に近い手法で、特定の周波数成分（特定の太さの線やエッジ）だけを浮き上がらせたり、背景の明るさムラを抑えて物体を強調したりするのに非常に有効です。

## 2. GUIの使い方
- **small_ksize_x / y**: 1つ目の（細かい）ぼかしサイズです。抽出したいターゲットの細かさに合わせます。
- **large_ksize_x / y**: 2つ目の（粗い）ぼかしサイズです。背景除去の基準となるサイズです。
- **offset**: 差分計算の結果に一律で加算する値です。計算結果が負になるのを防ぎ、結果を見やすく調整します。通常は中間値（8-bitなら128など）を指定します。
- **borderType**: 画像境界（端）の処理方法を選択します。

## 3. 注意点
- **8-bit**, **RGB (24-bit)**, **16-bit**, **32-bit Float** の各画像に対応しています。
- **offset** の指定可能範囲は画像のビット深度に依存します。
    - 8-bit / RGB: 0 - 255
    - 16-bit: 0 - 65535
- 内部的に32-bit浮動小数点(32F)で計算を行ってから元の型に戻すため、階調の連続性が維持されます。
