# WK_HoughCircles（ハフ変換による円検出）
## 1. 概要：画像処理の仕組み
画像の中から「円」を自動的に探し出すアルゴリズムです。
物体の輪郭が多少途切れていたり、ノイズが乗っていたりしても、円形に近い画素の集まりを統計的に処理して、中心座標と半径を特定します。

## 2. GUIの使い方
- **min_radius / max_radius**: 探したい円の最小半径と最大半径を指定します。
- **mode**: 角度の解像度です。値を大きくすると精度が上がりますが、メモリ消費と計算時間が増えます。
- **min_votes**: 円とみなすために必要な最低の投票数です。
- **range_to_judge_same**: 近接した複数の円を「同じもの」とみなす距離の範囲です。
- **enable_output_hough_image**: 計算過程のハフ空間画像（各半径ごとの投票結果）をスタック画像として出力します。

## 3. 注意点
- 入力画像は **8-bit Grayscale** である必要があります。
