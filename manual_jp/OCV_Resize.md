# OCV_Resize（画像のリサイズ）
## 1. 概要：画像処理の仕組み
画像の縦横サイズを変更（拡大・縮小）します。
単なる画素の抜き出しではなく、補間アルゴリズムを用いることで、拡大しても滑らかに、縮小してもディテールが潰れにくい高品質な画像生成が可能です。

## 2. GUIの使い方
- **dsize_w / h**: 出力画像の具体的な幅と高さです。
- **scale_factor_x / y**: 倍率による指定です（例：0.5で半分）。`0` 以外を入力するとこちらが優先されます。
- **interpolation**: 補間方法を選択します。
    - `INTER_NEAREST`: 高速だがジャギーが出やすい。
    - `INTER_LINEAR / CUBIC`: 一般的で高品質（Cubicの方がより滑らか）。
    - `INTER_AREA`: 縮小時に適した手法。

## 3. 注意点
- **8-bit**, **RGB**, **16-bit**, **32-bit** の全形式に対応しています。
- 実行後、リサイズされた新しい画像ウィンドウが開きます。
