# OCV_Scharr（Scharr演算子 / 境界検出）
## 1. 概要：画像処理の仕組み
Sobel演算子の精度をさらに高めたフィルタで、画像の輝度変化（エッジ）を計算します。
特に3x3の小さなサイズにおいてSobelよりも方向の精度が高く、わずかな色の変化も敏感に捉えることができます。x方向（縦線）またはy方向（横線）の変化を抽出するのに使われます。

## 2. GUIの使い方
- **dx / dy**: 微分する方向を指定します。一方が `1` なら他方は `0` にします。
- **scale / delta**: 結果の強調倍率と、最後に足すオフセット値です。
- **borderType**: 境界処理の方法です。

## 3. 注意点
- **8-bit**, **16-bit**, **32-bit Float** 画像に対応しています。
- `dx >= 0, dy >= 0` かつ `dx + dy = 1` である必要があります。
