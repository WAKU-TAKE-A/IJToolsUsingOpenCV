# OCV_NetFromOnnx_2nd_Inference（推論の実行）

## 1. 概要
`1st_Read` でロード済みのモデルを使用して、開いている画像に対して推論を行います。**物体検出**と**画像分類**の両方に対応しています。検出・分類結果はROIとして画像上に表示され、ResultsTableに情報が出力されます。

---

## 2. GUIの使い方

### score_threshold（信頼度しきい値）
検出・分類として採用する最低の信頼度（Confidence）を設定します。
- 低すぎると誤検出が増える
- 高すぎると検出漏れ・分類なしが増える

### nms_threshold（NMSしきい値）※物体検出モデルのみ表示
重複したボックスを統合するための閾値（IoU）を設定します。
- **画像分類モデル（YOLO_Class）を選択した場合は、このフィールドは表示されません**

### enable_results_table
チェックを入れると、結果を `ResultsTable` に一覧表示します。

### enable_refresh_data
チェックを入れると、`ResultsTable` とROIマネージャーをリセットしてから新しい結果を追記します。
- 複数画像を連続処理する場合はOFFにすると結果を蓄積できる

### enable_log
チェックを入れると、処理結果がログウィンドウに出力されます。

---

## 3. モード別の処理フロー

### 3.1. 物体検出モード（YOLO_Object_Pixel / Normalized / YOLOX_Object_Undecoded）

#### 前処理（Letterbox）
入力画像をモデルが要求する解像度（通常640x640）に変換します。

**Letterbox処理の手順：**
1. **アスペクト比保持リサイズ**
   - 元画像 480x640 → ratio=1.0 → 480x640（変化なし）
2. **グレーパディング**
   - 左右に80pxずつグレー(114,114,114)を追加 → 640x640
3. **正規化とチャンネル変換**
   - YOLO: 0-255 → 0-1、BGR → RGB
   - YOLOX: 0-255のまま、BGRのまま

#### 後処理
1. **出力の整形**: `[1, 84, 8400]` → `[8400, 84]`（各行が1つのボックス）
2. **信頼度フィルタ**: `score_threshold` 以上のボックスのみ抽出
3. **座標変換**: パディング除去・スケーリング・xywh→xyxy変換
4. **Per-class NMS**: クラスごとに重複ボックスを除去

### 3.2. 画像分類モード（YOLO_Class）

#### ROI対応
- **矩形ROIが選択されている場合**: その領域のみを切り抜いて分類
- **ROIなし（または非矩形）の場合**: 画像全体を分類

#### 前処理（単純リサイズ）
入力画像をモデルが要求する解像度（通常224x224）に直接リサイズします。
- letterboxは使用しない（分類モデルの標準的な前処理）
- 正規化: 0-1、チャンネル: RGB

#### 推論・後処理
1. **推論**: `[1, numClasses]` の出力を取得
2. **Top-1選択**: 最高スコアのクラスを1件選択
3. **閾値フィルタ**: `score_threshold` 以上の場合のみ出力
4. **ROI座標補正**: クロップしていた場合、座標を元画像基準に戻す

#### 出力
- 1件の結果（クラス名・信頼度）が物体検出と同じ形式で出力される
- ROIマネージャーに分類対象領域がROIとして登録される

## 4. 結果出力

### RoiManager
各ROIには以下の情報が含まれます：
- 名前: `"Chihuahua: 0.46"` （クラス名: 信頼度）
- 座標: 元画像上のピクセル座標
- 色: クラスIDに基づいて自動生成

### ResultsTable

**物体検出の場合：**

| カラム | 説明 |
|--------|------|
| Image | 画像ファイル名 |
| Label | クラス名 |
| Confidence | 信頼度（0-1） |
| X | 左上X座標 |
| Y | 左上Y座標 |
| Width | ボックス幅 |
| Height | ボックス高さ |

**画像分類の場合（ROI選択時はROI列も追加）：**

| カラム | 説明 |
|--------|------|
| Image | 画像ファイル名 |
| ROI | ROIを使用した場合に "Yes" と表示 |
| Label | クラス名 |
| Confidence | 信頼度（0-1） |
| X | 分類領域の左上X座標 |
| Y | 分類領域の左上Y座標 |
| Width | 分類領域の幅 |
| Height | 分類領域の高さ |

## 5. 注意事項

### 前提条件
- `1st_Read` でモデルが正常にロードされていること
- **入力画像はRGB（カラー）のみ対応**（8bitグレースケールはエラーとなります）

### 画像分類モードの制限
- 出力は **Top-1（最も確率が高いクラス1件）のみ**
- ROIは **矩形（Rectangular ROI）のみ**対応
- 非矩形ROI（楕円・フリーハンド等）は無視され、画像全体を分類

### NMS（物体検出のみ）
- Per-class NMSを採用。クラスが異なれば重なった物体も両方検出可能
- OpenCVの`Dnn.NMSBoxes()`は使用せず独自実装

---

## 6. トラブルシューティング

### ケース1: "Model is not loaded"
→ `1st_Read` を先に実行してください

### ケース2: 物体検出で座標がおかしい
→ `1st_Read` で選択した座標形式が間違っている可能性。別の形式を試す

### ケース3: 何も検出・分類されない
→ `score_threshold` を下げる（例: 0.5 → 0.1）

### ケース4: 画像分類でROIが効かない
→ 矩形ROI（Rectangle Tool）で選択しているか確認。楕円等は非対応。

### ケース5: グレースケール画像でエラーが出る
→ Image > Type > RGB Color で変換してから実行してください

---

## 7. 推奨ワークフロー

### 物体検出
1. 画像を開く（File > Open）
2. `2nd_Inference` を実行（score_threshold / nms_threshold を調整）
3. ROIが画像上に表示される
4. ResultsTableで座標を確認

### 画像分類
1. 画像を開く（File > Open）
2. 必要に応じて矩形ROIで分類したい領域を選択
3. `2nd_Inference` を実行（score_threshold を調整）
4. ROIにクラス名と信頼度が表示される

### 複数画像のバッチ処理
1. `enable_refresh_data` をOFFにする
2. 各画像に対して `2nd_Inference` を実行
3. ResultsTableに全画像の結果が蓄積される
4. ResultsTableを保存（File > Save As）
