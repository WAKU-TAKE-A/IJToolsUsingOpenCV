# OCV_GaussianBlur（ガウスぼかし）
## 1. 概要：画像処理の仕組み
ガウス関数（ベル状の分布）を用いて画像をぼかします。
単純な「平均化ぼかし」に比べて、中心からの距離に応じて滑らかに重みを減らすため、より自然で高品質なぼかし結果が得られます。画像ノイズの除去や、後の処理（エッジ検出など）を安定させるための前処理として最も標準的に使われます。

## 2. GUIの使い方
- **ksize_x / y**: ぼかし演算を行う窓（カーネル）のサイズです。大きいほど強くぼけます。
- **sigma_x / y**: ガウス分布の広がり（標準偏差）です。
- **borderType**: 画像の境界処理方法です。
- **Note**: `ksize` を `0` に設定すると、`sigma` の値から最適なサイズが自動的に計算されます。

## 3. 注意点
- **8-bit**, **16-bit**, **32-bit Float** 画像に対応しています。
- **ksize** を指定する場合は、必ず **正の奇数**（3, 5, 7...）である必要があります。
