# WK_Math（条件付き画素演算）
## 1. 概要：画像処理の仕組み
画像内の画素に対して、一括で四則演算（加算、減算、乗算、代入）を行います。
「すべての画素に10足す」といった全体処理だけでなく、「値が0の部分だけに特定の値をセットする」といった条件付きの編集が可能です。特定のマスク領域への値の書き込みなどに重宝します。

## 2. GUIの使い方
- **math**: 演算の種類（add, sub, multiply, set）を選択します。
- **value**: 演算に使用する数値です。
- **conditions**: 
    - `all`: 全画素を対象にします。
    - `equal_zero`: 画素値が 0 の場所のみ処理します。
    - `not_zero`: 画素値が 0 以外の場所のみ処理します。

## 3. 注意点
- **8-bit, 16-bit, 32-bit Float** 画像に対応しています。
- 内部的に32-bit浮動小数点として計算するため、オーバーフロー（255を超えるなど）を考慮した柔軟な計算が可能です。
