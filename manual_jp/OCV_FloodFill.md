# OCV_FloodFill（シードフィル / 塗りつぶし）
## 1. 概要：画像処理の仕組み
指定した座標（シード点）から、色が近い隣接領域を特定の法で塗りつぶす、いわゆる「バケツ」ツールです。
単なる塗りつぶしだけでなく、「元の色から±○の範囲なら同じ領域とみなす」といった柔軟な指定が可能で、ノイズがある画像での領域抽出にも利用されます。

## 2. GUIの使い方
- **newVal_B / G / R**: 塗りつぶす新しい色（輝度値）です。
- **loDiff_B / G / R**: 下方向への色の許容差です。シード点よりこの値だけ暗い画素まで塗りつぶします。
- **upDiff_B / G / R**: 上方向への色の許容差です。シード点よりこの値だけ明るい画素まで塗りつぶします。
- **flags**: 連結性と動作モード。
    - `4-connected` / `8-connected`: 隣接画素を4方向か8方向かで判断します。
    - `FLOODFILL_FIXED_RANGE`: チェックを入れると、各画素を「シード点」と比較します。外すと「隣り合う画素同士」で比較します。
- **addMessage**: 8-bitや32-bit画像の場合は `*_B` の値のみが使用されます。

## 3. 注意点
- **8-bit**, **RGB (24-bit)**, **32-bit Float** 画像に対応しています。
- 実行前に、**ROI Managerにシード点（Point ROIなど）を少なくとも1つ登録**しておく必要があります。選択されたROIの座標が塗りつぶしの開始点になります。
